## The rule for V1

**A visitor can find the right product and send InflexHub a well-formed inquiry, and the owner can count demand per product and industry.** The site looks and feels finished, premium, and complete. Content and catalog are static files; forms are fully dynamic and stored.

## Out of V1

Bot protection widget, visitor auto-reply email, analytics, production deploy → [V1.1](v1.1.md). Admin panel, database-driven catalog and content, lead statuses → [V2](v2.md).

## Extension points (why V2 needs no rework)

| In V1 | What V2 builds on it |
|---|---|
| Stable product slugs in `catalog/products.json` | V2 seeds the `products` table from the same file; slugs stay the keys |
| Inquiries store slug + name/category/availability snapshot | Demand reports work across V1 and V2 data |
| `status` column with reserved values (BR-9) | Admin pipeline changes status; history table added |
| `ICatalog` interface in Application, JSON implementation in Infrastructure | V2 swaps in a database implementation; handlers unchanged |
| Site reads catalog through one module (`src/lib/catalog.ts`) | V2 changes that module to fetch from the API |
| Content files typed by section (`src/content/*.ts`) | V2 maps the same types to CMS blocks |

## Exit criteria

- [ ] Every `@v1` scenario in [user-stories](../user-stories.md) is implemented and has a test or a `@ui` manual check
- [ ] All seven inquiry types store exactly one inquiry and show the reference
- [ ] With SMTP configured, a test inquiry reaches the sales inbox; the CSV export opens correctly in Excel
- [ ] Demand views return correct counts for seeded data
- [ ] Lighthouse mobile ≥ 90 (performance, accessibility, SEO) and Core Web Vitals good (LCP ≤ 2.5 s, INP ≤ 200 ms, CLS ≤ 0.1) on home, products, product detail
- [ ] axe-core: no serious/critical violations; CSP active with no console violations; securityheaders.com grade A
- [ ] Keyboard-only walk-through of every form works; contrast checked
- [ ] Owner reviewed the content (OV-2, OV-3) and the catalog (OV-1)
