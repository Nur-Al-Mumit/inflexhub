# V1.1 — Launch hardening

Status: Draft
Index: [scope/](README.md) · Previous: [V1](v1.md) · Next: [V2](v2.md)

## Goal

Make V1 safe and visible in production.

## In V1.1

| Item | Notes | Blocked on |
|---|---|---|
| Cloudflare Turnstile on every form | Server-side verification in the API (no package) | Turnstile keys |
| Resend failed sales emails | Background job resends inquiries with `sales_notified_at` null (the email itself ships in V1) | — |
| Auto-reply email to the visitor with the reference | Plain, branded template | OV-12 |
| Cloudflare Web Analytics | Privacy-friendly, no cookie banner needed | OV-11 |
| Production deploy | Docker on a VPS behind Cloudflare; TLS 1.2+ only; HSTS with preload | OV-11 |
| Email authentication | SPF, DKIM, DMARC on the sending domain before production email | OV-11, OV-12 |
| Backups | Daily encrypted PostgreSQL backups, 3-2-1 rule, RPO 24 h / RTO 4 h (ASSUMPTION), quarterly restore test | OV-11 |
| Monitoring | Uptime Kuma on the health endpoint; Serilog to Seq | — |
| Legal review | Privacy policy and terms | OV-7 |

## Exit criteria

- [ ] Site live on the domain over HTTPS; health monitored
- [ ] A test submission reaches the sales inbox within one minute in production
- [ ] Database backup restored once on a test machine
