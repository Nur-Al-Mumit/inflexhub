## Goal

InflexHub staff run the catalog, the website content, and the sales pipeline without a developer, and see demand at a glance.

## In V2

| Area | Item |
|---|---|
| Admin app | Separate Next.js app `web/apps/admin` on its own subdomain; staff sign-in with cookie + BFF sessions and mandatory 2FA; roles: admin, sales, content editor |
| Products | Create, edit, archive products; categories; industries; availability changes (audited); feature and module lists; images; SEO fields; publish / draft |
| Website content | Editable content blocks for home, about, industries, FAQs, company details; publish with preview |
| Inquiries and leads | List with filters (type, product, industry, status, date), detail, status pipeline (BR-9 values), notes, assignment to a sales person, status history, CSV export |
| Demand analytics | Dashboard: inquiries over time; by product, category, industry, availability, type; interest ranking of upcoming products; conversion by status |
| Public site | Reads catalog and content from the API with incremental static regeneration (revalidate on publish) |
| Audit | Every admin change written to an audit log |
