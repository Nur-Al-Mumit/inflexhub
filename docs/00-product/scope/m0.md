## Goal

A walking skeleton: every layer exists, builds, tests, and runs together, so V1 only adds features.

## In M0

| Area | Item |
|---|---|
| Repository | Root `README.md`, `AGENTS.md`, `.gitignore`, `.editorconfig`, docs set |
| Backend | `InflexHub.slnx` with Domain, Application, Infrastructure, Api, Application.UnitTests; `Directory.Build.props` (nullable, warnings as errors in CI); `Directory.Packages.props` (central versions) |
| Backend wiring | Cortex.Mediator + FluentValidation pipeline behaviour; ProblemDetails with error slugs; Serilog (no personal data); `IClock`; health endpoints `/health/live` and `/health/ready` (database) |
| Database | EF Core `AppDbContext` with Npgsql, first migration, snake_case naming |
| Frontend | `web/` npm workspace with `apps/site` (Next.js 16, TypeScript strict); design tokens; fonts; layout shell (header, footer) |
| Catalog | `catalog/products.json` readable by both the site and the API |
| Docker | `docker-compose.yml` with `postgres:18`, `api`, `site`; Dockerfiles for API and site; `.env.example` |
| CI | Build + unit tests for backend and frontend (`.github/workflows/ci.yml`) |

## Exit criteria

- [ ] `dotnet build InflexHub.slnx -warnaserror` and `dotnet test InflexHub.slnx` pass
- [ ] `npm run typecheck && npm test && npm run build` pass in `web/`
- [ ] `docker compose up --build` serves the site on :3000 and the API health on :8080
