# InflexHub public site

Next.js 16 App Router site (React 19, TypeScript strict, CSS Modules, design tokens in `src/styles/tokens.css`). The shared product catalog is read through `src/lib/catalog.ts` (from V1). Rules: [AGENTS.md](./AGENTS.md); architecture: [docs/04-frontend/nextjs-architecture.md](../../../docs/04-frontend/nextjs-architecture.md).

Run from `web/` (npm workspace root): `npm install` · `npm run dev` (:3000) · `npm run typecheck` · `npm test` · `npm run build`.
